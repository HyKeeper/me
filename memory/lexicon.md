# 公共词表（Lexicon）

> **可随仓库开源。** 只含「词 → 标准名」映射，是公开知识，不含任何"某人是谁 / 某人在哪"的绑定关系。
> 私人实体（人名、家庭关系、"我们公司"这类指代）一律放 `_aliases.md`（不进仓库）。
>
> **设计原则：这份表要足够大、足够中性。** 覆盖全国主要城市、主要行业、主要技术栈，
> 因此任何单个使用者的生活痕迹都会被稀释成其中一页——词表本身不构成任何人的画像。
> 判定准则：**这一行换个人还成立吗？** 成立 → 留这里。
>
> 优先级：`_aliases.md`（私人绑定） > 本表（精确映射） > `_synonyms.md`（语义概念泛化）。
> 组内按标准名的拼音/字母序排列。
