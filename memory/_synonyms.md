# 同义词 / 概念归一化表

> 用途：`scripts/semantic.py` 在切词前把口语同义词归一成同一个概念 token。
> **本表只放「语义概念」，不放「具体实体」。** 实体（公司名、人名、地名、内部系统）一律进 `_aliases.md`——
> 前者任何中文用户都通用，后者因人而异且可能含隐私。开源模板见 `_synonyms.example.md`。
> 不这样做，问「医保社保扣多少」永远匹配不到写着「五险一金」的条目 —— 这是纯字面检索的固有缺陷。
> 本文件是索引不是属性，`scripts/check.py` 跳过 `_` 开头文件。

## 维护规则

- **概念名取最短且无歧义的那个**，同义词全部登记在同一行。
- 一个词只能属于一个概念。发现归属冲突时，拆分成更细的概念，不要让它同时挂两处。
- 新增概念时，同步在想清楚"这个词在用户嘴里可能长什么样"，把口语变体都写进去。
- 匹配按**长度降序**进行，避免「五险一金」被「五险」抢先切断。
